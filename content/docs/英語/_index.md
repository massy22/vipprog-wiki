# どの程度の英語力が必要か {#wa0a354b}
基本的に理系の文章は、<strong>簡潔</strong>で<strong>明快</strong>である事が求められます。これは英語も日本語も一緒です。小説のようにごちゃごちゃした表現や、1文で複数の意味を持たせたりするような事はありません。なので必要とされる英語力は文法に限って言えば中学生レベルでも構いません。

英語をネイティブに話す人の割合の方が少ないわけですから、怖がらずにチャレンジして下さい。
