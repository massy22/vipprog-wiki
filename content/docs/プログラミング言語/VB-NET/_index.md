# VB.NET {#qa5abaa5}


# 言語の特徴 {#tc544b98}
正式名称は<em>Microsoft Visual Basic .NET</em>
VB.NETはMaicrosoftが同社の.NET Frameworkの開発環境として提供している言語です。
Basicをベース言語として、他の.NETと同様にGUIをグラフィカルに設定できる比較的初心者向けの言語ともいえる。
最新バージョンはVB 2008だが、以前のバージョンの６と比べて機能の変更点が多くVB6のユーザーも多数いる

開発環境として無料版のExpress Editionがある

# 開発環境の導入 {#vb8e01c2}
Maicrosoftの[Visual Basic 2008 Express Edition 日本語版](http://www.microsoft.com/japan/msdn/vstudio/express/)よりダウンロードし実行を行う
ダウンロードにはサインインする必要があるので登録が必要。

[C#](/docs/プログラミング言語/C-Sharp)の解説とほぼ同様に導入することができる
