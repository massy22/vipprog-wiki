# なでしこ {#oaaa66e3}


## はじめに {#k86f9698}
### 概要 {#o853bc2a}

- 日本語のプログラミング言語です
- 先代の言語に「ひまわり」があります。


### メリット {#jb61879a}

- 動作が軽快(ひょっとすると下手なVBより軽快(・∀・)!!)
- 導入が簡単(統合開発環境、リファレンス等が全て無料で入手可能)
- ライブラリもちょっとずつながら整ってきている


### デメリット {#pc283d4b}

- 日本語記述なので慣れない人は苦しい
- <del>生成EXEは配布するときに必ずDLLを同梱しなければならない</del> → EXE1ファイルにまとめられるようになった模様
