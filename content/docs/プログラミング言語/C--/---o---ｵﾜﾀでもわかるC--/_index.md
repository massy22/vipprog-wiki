# 準備 {#i0802fe8}
＼(^o^)／よう！<br />
俺だよ俺！<br />

## 始めるにあたって {#z2888bc2}
＼(^o^)／C++に限らないけど、プログラムの勉強するときは以下の事を心がけてくれよな！<br />

- ソースは読むだけじゃなく書け！
- 書いたソースは必ず実行確認しろ！


## 環境を整える {#y949c1f4}
＼(^o^)／C++のコンパイラは色々とあるんだけど、<br />
とりあえずWindowsでお手軽にやりたいなら
[Microsoft Visual Studio 2005 Express Edition](http://www.microsoft.com/japan/msdn/vstudio/express/visualc/)
をインストールするんだぜ。<br />
これなら、C++にこなれてきた頃にWindowsGUIアプリケーションの開発もできるようになるしな！<br />

ちなみにインストールまでがめちゃくちゃめんどいから気長にがんばれよ！

# はじめの一歩 {#q4e80a3d}
＼(^o^)／それでは最初に簡単なプログラムを作ってみるぞ！<br />
VisualC++（以下VC）でプログラムする基本的な手順をここでマスターするんだぜ。<br />

## プロジェクトの作成 {#v8dfa8ef}
＼(^o^)／VCを起動して、以下の手順で「hello」プロジェクトを作ってみるんだぜ。<br />

1. [ファイル]→[新規作成]→[プロジェクト]を選択
1. 新しいプロジェクトダイアログが表示される
1. [プロジェクトの種類]の[Win32]を選択
1. [テンプレート]に[Win32 コンソール アプリケーション]が指定されている事を確認
1. [プロジェクト名]に「hello」って入力
1. [OK]ボタンを押下


できたか？<br />
これはWindowsのコンソール（コマンドプロンプト）で動くアプリケーションを作るときの手順だから、<br />
とりあえずおまじない的に覚えておいてくれよな！

## ソースファイルの作成 {#ib9cf043}
＼(^o^)／VisualStudioの左側に、<br />
ソリューションエクスプローラーっていうウィンドウが表示されたか？<br />
エクスプローラーみたいなやつな。<br />
ここに、今度はソース（プログラム）ファイルを作ってみるんだぜ。<br />

1. [ソリューション エクスプローラ]の[hello]ノードを開く
1. [ソースファイル]ノードを右クリック
1. [追加]→[新しい項目]を選択
1. [新しい項目の追加 - hello]ダイアログが表示される
1. [カテゴリ]の[VIsual C++]→[コード]を選択
1. [テンプレート]の[C++ ファイル(cpp)]が選択されていることを確認
1. [ファイル名]に[main]って入力
1. [追加]ボタンを押下


手順ってのは文章にするとやたらとめんどくさそうに見えるよな！<br />
実際はたいしたことやってないから、<br />
何回かやってみて体で覚えてほしいんだぜ。

## Hello world! {#t5f77bbb}
＼(^o^)／いよいよプログラムだぜ！<br />
ここまでの手順で、main.cppっていうテキストエディタが表示されているよな？<br />
ここに、以下のプログラムを打ち込んでみるんだぜ。<br />

<strong>コーディング</strong><br />


```
#include <iostream>
using namespace std;
int main()
{
  cout << "Hello world!" << endl;
}
```


できたか？<br />
これがいわゆるC++のソースコードなんだぜ。<br />
何をやってるかは追い追い説明するから、<br />
今は手順通りに進んでくれよな！<br />

次は、このソースから実行ファイル(EXE)を作るための、<br />
「ビルド」をやってみるぞ。

<strong>ビルド</strong>

キーボードの「F7」を押すとビルドが開始されて、<br />
VisualStudioの下の方に「出力」っていうウィンドウが表示されるよな。<br />
ここの一番最後の行に、<br />

```
========== ビルド: 0 正常終了、0 失敗、1 更新、0 スキップ ==========
```

こんなのが表示されてたら、ビルド成功なんだぜ。<br />
もし、失敗が0じゃない時はソースのどっかがおかしいはずだから、<br />
間違いを直してもう一回ビルドするんだぜ。

<strong>実行</strong>

最後に、ビルドしたプログラムを実際に実行してみるんだぜ。<br />
キーボードの「F5」を押すと、黒くて四角い何かがちらっと表示されるよな。<br />
早くて見えないだろ？これ、コンソールアプリの実行結果なんだぜ。

## 見えないのをなんとかする {#y3c598e9}
＼(^o^)／コンソールアプリを実行したら、<br />
黒い四角がちらっと表示されてｵﾜﾀよな。<br />
これは何かというと、さっきの一瞬でプログラムが実行されて、<br />
そして終了しちゃったってことなんだぜ。<br />

これじゃ何やってるのかちっともわからないよな。<br />
なので、ソースをちょっと修正して、<br />
終了する前にちょっと待っててもらうようにしてみるんだぜ。<br />


```
#include <iostream>
#include <conio.h>  // 追加
using namespace std;
int main()
{
  cout << "Hello world!" << endl;
  _getch(); // 追加
}
```


修正したソースをビルドして実行すると、<br />
今度は黒くて四角て、「Hello world!」って書かれたコンソールが表示されてるはずなんだぜ。<br />
何かキーを押すと終了するから、<br />
とりあえずEnterでも押して消しておいてくれよな！

## ソースの説明 {#wb863f24}
＼(^o^)／それでは、さっきスルーしたソースの説明をしてみるんだぜ。<br />


```
#include <iostream>
```


ここでは「iostream」というC++標準クラスライブラリを、<br />
hello.cppから使えるようにするための宣言をしてるんだぜ。<br />
iostreamっていうのは、コンソールに文字を表示するのに必要なんだぜ。


```
#include <conio.h>
```


さっき追加した「何か押すまで待つ処理」を実装するために、<br />
C標準ライブラリのconio.hをインクルードしてるんだぜ。


```
using namespace std;
```


C++標準クラスライブラリをバリバリ使うよ～っていう宣言なんだぜ。<br />
下で説明するんだぜ。


```
int main()
```


「main」っていう関数（一連の処理）を宣言してるんだぜ。<br />
コンソールアプリでは、この関数が一番最初に実行されるんだぜ。


```
{
```


「ここからmain関数始めるよ」という目印だぜ。


```
  cout << "Hello world!" << endl;
```


「Hello world!」をコンソールに出力してるんだぜ。<br />
もう少しｋｗｓｋ書くと、<br />
cout（標準出力）に、「Hello world!」を出力して、<br />
さらにendl（改行）を出力してるんだぜ。

ちなみに、上で説明した「using namespace std;」を省略すると、<br />
std::cout << "Hello world!" << std::endl;<br />
っていうふうに、「std::」を付けて書かなくちゃいけないんだぜ。


```
  _getch();
```


これは、キーが押されるまで待っててくれる関数なんだぜ。<br />
こ難しく説明すると、<br />
標準入力から１文字受け取るまで待機する関数なんだぜ。


```
}
```


main関数はここまでっていう目印なんだぜ。
