## C++とは？ {#g849093d}

　C++はC言語にオブジェクト指向の考え方を取り入れた、
ゲーム製作向けとしては現行で一番メジャーなプログラム言語です。
3Dゲームが多いですがもちろん2Dも可能です。
　C言語は他のほとんどの言語の元になっているため、これさえ覚えれば
他の言語を習得する際大変楽になります。

## 早速つくってみる {#e1e29ac0}

では、早速常套に則ってプログラムの世界にコンニチワしましょう。
適当なｴﾃﾞｨﾀに、以下の簡単なプログラムを記述してください。
＜重要＞できるだけ手打ちで入力する事！


```
#include<stdio.h>
void main (void)
{
 printf("Hello,World!\n");

}
```


とりあえず起動してみましょう。
コマンドプロンプトが開いて「Hello,World!」と表示されているはずです。
ここから文字を表示する仕組みについて書きます。
