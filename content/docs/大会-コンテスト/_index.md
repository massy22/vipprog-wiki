## CodeChef {#t2782a4e}
最強インド人プログラマを養成するために創られたサイト。<br />
もちろんインド人以外も参加できます。問題文は英語。<br />
月の始めごとに２週間ぐらいの期間のロングコンテストが、また、月に一度は2時間半ぐらいの制限時間のショートコンテストがあります。

[CodeChef](http://www.codechef.com/)

## ICFP Programming Contest {#i3a941b2}
国際関数型言語学会主催．毎年7月ぐらいに3日間行われる．
世界最強の言語を決める大会でもある．2007年はHaskell，2006年はC++だった．
特に参加制限は設けられない．賞金あり．問題は難しい．量多い．

[The Eleventh ICFP Programming Contest](http://www.icfpcontest.org/)

## Image Cup {#q0d86267}
マイクロソフト主催．学生のためのプログラミングコンテスト．
大会告知の人は世界大会まで行きましたね．競技部門いっぱいあるのでレッツチャレンジ

登録するだけでいろいろソフトが落とせたりするので学生は要注目．<br />
→'09大会からは、参加登録のみの者の入手可能ソフトウェアが削られた代わりに、第一ラウンド課題提出者およびITラウンド1突破者にはサーバソリューションなどおおよそ80本くらいのソフトウェア(総額不明)が配布されることに。

[Image Cup](http://www.microsoft.com/japan/academic/imaginecup/about.mspx)

## ACM国際大学対抗プログラミングコンテスト {#af528efa}
大学生・M1生のための、プログラミングコンテストです。3人1チームで各学校から何人チームでも出られます。<br />
まず、国内予選があって、それを通過したチームがアジア予選に出ます。そして、日本代表(1~3チーム)を決めて、<br />
世界大会に出場します。<br />
国内予選は、ネット越しにどこからでも参加でき、いわゆるBランク以上くらいの大学なら毎年1チームは通過してますが、<br />
世界大会に出られるのは、大抵、京大・東大・東工大です。

[ACM 国際大学対抗プログラミングコンテスト](http://sparth.u-aizu.ac.jp/icpc2008/?lang=jp)

## EPOCH＠まつやま(愛媛大学プログラミングコンテスト) {#g5715360}
大学生以上を対象とした競技形式（早く正確に解く）のプログラミング大会などで全国大会・国際大会相当で入賞した経験のある方はご遠慮ください．（＊本大会はプログラミング人口のすそ野を広げることを主たる目的としているため）
と書かれてはいるが･･･

[EPOCH実行委員会](http://epoch.cs.ehime-u.ac.jp/index.html)

## RICOH & Java Developer Challenge {#pb724efb}
複合機を使ったプログラミングコンテスト。大学生以上の学生が対象。組み込みではあるが携帯電話くらいのJavaが動くのでそれほど専門的知識は要求されない。コードの他にドキュメントやプレゼンまで評価対象になる。ぶっちゃけアイデア勝負。

申し込みをすれば講習会で1回東京に行ける。最終選考会に残ればもう1回東京に行けるので地方の学生にとっては魅力的。最終選考会で貰えるノベルティグッズのセンスがいい。

mixiにコミュニティがあるので、過去の参加者にいろいろ聞くと有利。

[RICOH & Java Developer Challenge](http://www.ricoh.co.jp/javachallenge/)

## U-20 プログラミングコンテスト {#d97b1cd0}
参加資格はU20であることのみ！ 経済産業大臣賞や経済産業省商務情報政策局長賞など賞がなんか凄そうなのが特徴。
受賞できればドヤ顔し放題。中学生とかも入賞してるし未公開じゃなくても公開後1年以内であればおｋらしいのでとりあえずゴミみたいなの送り付けとけばいいと思う。

[U-20 プログラミングコンテスト](http://www.johogekkan.jp/procon/)
