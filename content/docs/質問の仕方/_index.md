# どんな質問にも共通して {#p7de642b}
とにかく回答者が質問を見たときに、「ああ、こういうことで困ってるんだな」ってことが分かることが大切です。

```
「Cでプログラミングしててエラーが出るんだけど」
```

とだけ言われても何も分からないのでこういうのはダメだよ、ってことです。

# プログラミング固有 {#kefbcd02}

「うまくいかない」だけでなく、なるべく具体的に、質問したい部分が最小限再現できるコードを一緒に書きましょう。
それを調べている途中で解決してしまうことも多いと思います。

例えば

- 言語
- 最小限の再現コード
- 自分が求める結果・実際に出てくる結果
- 実行手順(コンパイルのコマンドなど)
- エラーメッセージ


などが書いてあると回答者側での再現性が上がるので、解決しやすくなります。

エラーが出ない場合は厄介なパターンであることが多いです。回答者もすぐには気付かないかもしれないので、分かりやすさを強く意識しましょう。
