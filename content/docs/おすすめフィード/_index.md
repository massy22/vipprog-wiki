# みんなどこのRSS購読してる？ {#a3d368b6}

超ハイパーストライクウルトラプログラミングスレンダースーパー剣！<br />
[takeshima.2ch.net/test/read.cgi/news4vip/1233135544/](https://kako.5ch.io/test/read.cgi/news4vip/1233135544/) より
> 

```
26 名前：以下、名無しにかわりましてVIPがお送りします[sage] 投稿日：2009/01/28(水) 20:49:37.82 ID:et0fvlQF0 (PC)
  保守代わりに思いつきのネタなんだけど。
  みんなどんな（どこの）RSS購読してるんだろ？
  もしまとまった数集まるならカテゴリ毎に分けるとかしてWikiにまとめても面白いかなー、なんてね。
```


ということで、ゆっくり書いていってね！！！

あ、それから、フィード<sup id="fnref-1" class="footnote-ref"><a href="#fn-1">*1</a></sup>の購読にはフィードリーダー<sup id="fnref-2" class="footnote-ref"><a href="#fn-2">*2</a></sup>やRSS機能のあるウェブブラウザ、電子メールクライアント<sup id="fnref-3" class="footnote-ref"><a href="#fn-3">*3</a></sup>などを利用して下さい。<br />

このページのフィードをOPML<sup id="fnref-4" class="footnote-ref"><a href="#fn-4">*4</a></sup> に纏めて提供する、という話もありますが、
いづれ誰か用意してくれることでしょう。<br />
ですので今の所フィードを纏めて登録したい場合、例えば [livedoor Reader - RSSリーダー](http://reader.livedoor.com/)のブックマークレット、『まとめて購読 』<sup id="fnref-5" class="footnote-ref"><a href="#fn-5">*5</a></sup>をこのページに対して使う、などのような手段を講じてください。

### プログラミング初学者向けの説明 {#beginner}
Pipes Editor で[GUI](/docs/プログラミング用語#gui)な環境でPipesを編集するのは、<br />
プログラミングにおける３大制御構造： 順次（逐次）・選択（分岐・判断）・反復（繰り返し）、の理解に役立つと思います。<br />
どのモジュールがどの制御構造にあたるのか、考えながら編集してみて下さい。<br />
また、入力データは？出力データは？アルゴリズムは?などに注目してプログラムの流れを見てみて下さい。<br />
参考書を読むのも大事ですが、たまにはこういう作業も、きっと面白いと思います。
