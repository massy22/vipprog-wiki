# 進路の選び方 {#tbdf8dc7}


# プログラマとは {#f5ae0279}
プログラマとは実際にコーティングをする人のことを言います。と、言ってもプログラマも様々ですが。別名<strong>デジタル土方</strong>。現代に鬱病が増えたのはプログラマのおかげとも言われるほど心を病んでしまう人が多いようです。<strong>偽装請負</strong>なども常態化し、身分が不安定な事も。日本では刺身にたんぽぽを乗せる仕事と同列に扱われ給料も低め。私が死んでも代わりがいるものを地でいく業界です。なろうと思えばプログラミングをまったくしらなくても、文系でもなれます。

# ゲームプログラマとは {#bda3fd3f}
日本において10秒で1年分の法定被曝量を浴びてしまう原発のボルトを締める仕事に次いでやばい仕事の一つ。僕が言いいたいのは<strong>やめとけ</strong>。

# SEとは {#b3ee4ad0}
SEはいろいろあるけど基本的にはプログラマを遣う立場の人。この人によってプロジェクトが<strong>デスマーチ</strong>になるかならないか決まる。自分がコードを書くことはあんまない。
プログラマ30歳定年説にあるように30くらいでプログラマから転向する人も多いです。

# 趣味グラマ {#h215ab79}
趣味で日曜日などにプログラミングする人たちのこと。<strong>真の勝ち組</strong>とも言う。

# 大学の選び方 {#y51794b9}
いろいろ書くのめんどうだから一つ。<strong>理系ならできるだけ国立</strong>(私立でも良いが学費が違う)。なるべく<strong>偏差値は高く</strong>。<br />
特に上を目指さなければ、スキル低くてもPGやSEで十分食っていけます。<br />
専門でもＦラン大でも問題なし。高卒レベルの数学・英語は必須。<br />
本当の技術なんつーもんは、一部のスーパーPGやSEに任せときましょう。<br />
スーパーPGやSEは異常にデキる奴が多いので一般人が無理をすると欝になります。

## 人で選ぶ {#nd8bd8a2}
いい学校にはいい人が集まるってものです．
プログラミングコンテストとか出たい人は偏差値高いとこ狙ってみるといいと思います．
すぐにチーム組めるし，入賞できる可能性も高いです．
大会告知の人と一緒に大会出たいからSFCに行きたい！とかあると思います．

## 偏差値で選ぶ {#z5453238}
偏差値で選んだって悪い事はありません。結構メリットがあります。
たとえば奨学金。どっかの奨学金を騙った学資ローンは卒業後に返還が必要ですが、返還の必要のない奨学金ももちろんあります。

大手の私学などはかなり充実していて、[早稲田大学奨学金](http://www.waseda.jp/syogakukin/)や[慶応義塾大学奨学金制度](http://www.gakuji.keio.ac.jp/life/shogaku/system_gakubu.html)などはかなりの人数が採用されます。OBらによる寄付による影響はかなり大きいです。貧乏でなくとも成績だけで貰える奨学金もあります。もちろん学生間の競争も激しいですけど。

企業も社会貢献の一環として企業奨学金制度を設けているところもあります。ただし、企業奨学金制度は指定校制度を取っているところもあり、例として[電通育英会](http://www.dentsu-ikueikai.or.jp/graduate/select/)では偏差値高目の大学しか応募資格がありません。

偏差値が高い≒お金を持ってる（絶対じゃないけど）なので、高偏差値の大学はそれだけ学生の支援に力を入れているところが多いです。東大は年収400万以下なら授業料全額免除です。授業料免除は大学の予算から出しているので、お金がない大学は授業料免除の枠が少なくなります。いわゆる駅弁大学なら年収400万では半額免除も難しいでしょう。

## 1ランク下で選ぶ {#nc8b2f03}
身の丈に合わない大学に行って苦労するってこともあります．
それならランクが下の大学を狙ってみるのもありでしょう．

大学には成績上位者には返さなくてもいい奨学金の制度があったりします．
また，早期卒業の道もあります．
大学内で上位の成績が取れるといいことが多いので，これを狙うのもありかもしれません．

## お金で選ぶ {#m879ccc9}
ここでのお金は研究費のことです．

をご覧ください．
国立の場合，偏差値と研究費は比例します．
旧帝ぐらいになるとスパコンがありますが，駅弁にそんなもんありません．

メモリ100Gくらい使ってなんかしてーって人は東工大とかオススメします．

## 就活で選ぶ {#eed1eebf}
地方の大学は過ごすのにはいいですが，就活が大変です．
金銭的にも，時間的にも，肉体的にも．
今の企業って交通費出してくれないんですよね…．

将来的にどこで働きたいかを考えて大学を決めるのも大事です．
とりあえず首都圏なら就活は無敵．


## 情報工学科じゃないとダメですか？ {#r0efd29d}
そんなことはありません。基本的に理系の学部であればどこでもいいと思います。情報工学科の先生も物理科や化学科や医学科などから来てる先生もいます。どこに行ってもコンピュータと関わる事になるでしょう。また文系の学部でも学べるところがあるようです。文系プログラマも多くいますので、文系の方も挑戦してみましょう。

## いろいろあって決められない {#d1bf6ca4}
大学にはいろいろ研究室があって、たいていサイトを持っています。研究実績や就職実績などを載せていますので見るだけでもいいと思います。またニュースなどでは研究室の名前も報道されるので、おもしろそうなニュースを見つけたらチェックしておくのもいいかもしれません。

工業高校から高専への編入はもっと楽<br />

工業→高専→大学なんていう学歴ロンダもあり<br />

ただし、赤点の基準も高く、留年することも多いのでしっかり勉強できる人でないとお勧めできない。
